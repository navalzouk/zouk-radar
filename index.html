Reading this table: Meta ROAS is Meta's own reported purchase conversion value ÷ Meta spend for that hour — a Meta-attributed view, distinct from the blended ROAS shown elsewhere. ASR (ad-spend ratio) is (Meta + Google spend) ÷ net sales (=Revenue) for that hour — the inverse view, on a net-of-returns basis. The small +/− figures next to Meta, Total spend and Revenue compare each hour to the same hour on the previous day (apples to apples), not the hour before it. Revenue's chip is green when up, red when down; Meta and Total spend are a cost, so their chips run the opposite way — green when spend is down, red when it's up. ASR's small figure is different: rather than a % change, it's the previous day's ASR at that same point — the same hour, or for "Till Day," the same cumulative-to-hour window — shown as a value so it's directly comparable. The color lives on the main ASR figure, not that reference figure: green means it's the lower (better) of the two, red means higher; the reference figure itself is left uncolored. "Till Day" is the selected day's cumulative total so far, compared the same way against the previous day's total through that same point. Rows with no spend and no orders are dimmed.
